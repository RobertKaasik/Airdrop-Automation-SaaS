Перед включением авторежима

Приложение начнёт само отправлять операции с вашего кошелька — без вашего подтверждения каждый раз.

  • Ключи остаются только на этом компьютере и хранятся в защищённом месте Windows
  • Операции будут уходить сами, как только подойдёт время по расписанию
  • Проверяйте расписания на сайте: ошибочная задача тоже выполнится
  • Если ключ потеряется или его украдут, вернуть деньги через это приложение нельзя
  • Если с сайта придёт неверная команда, деньги с кошелька могут уйти

Включайте только если доверяете AIRDROP-X и этому компьютеру.
